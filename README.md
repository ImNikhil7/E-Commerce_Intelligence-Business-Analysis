# E-Commerce Sales Analytics

## Project Overview

This project simulates a real-world data analytics engagement for an e-commerce company ShopSphere.

The objective is to analyze sales performance, customer behavior, product trends, and business KPIs to identify opportunities for increasing revenue and improving operational efficiency.

The project follows the complete data analytics lifecycle:

- Business Understanding
- Data Cleaning
- Exploratory Data Analysis (EDA)
- SQL Analysis
- Data Visualization
- Business Insights
- Actionable Recommendations
