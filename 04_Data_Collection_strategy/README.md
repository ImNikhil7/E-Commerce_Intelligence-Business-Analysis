# Phase 4 — Data Collection & Source Strategy

## Purpose

This phase evaluates possible data sources and defines how the selected
source will be acquired, preserved, validated, and incorporated into the
ShopSphere analytical workflow.

## Documents

- `Data_Acquisition_Plan.md`
- `Data_Collection_Strategy.md`
- `Data_Quality_Risks.md`
- `Source_Evaluation.md`

## Primary Source

The project uses the Olist Brazilian E-Commerce Public Dataset as the
primary source for observed transactional, customer, product, payment,
review, geographic, delivery, and seller-acquisition data.

## Data Policy

Original source data is preserved separately from processed datasets.

The workflow is:

Raw Data
→ Validation
→ Cleaning
→ Transformation
→ Analysis-Ready Data

## Data Quality Considerations

Key risks include:

- Missing values
- Duplicate records
- Referential integrity issues
- Date consistency
- Historical-data limitations
- Missing business attributes
- Synthetic-data risks
