## Non Functional requirements of the Project.
| Requirement     | Description                                                                 |
| --------------- | --------------------------------------------------------------------------- |
| Performance     | Dashboard should load in under 5 seconds for the expected dataset size.     |
| Scalability     | New years of sales data should be added without redesigning the project.    |
| Reliability     | KPI calculations should be consistent across SQL, Python, and Power BI.     |
| Maintainability | Code should be modular and well documented.                                 |
| Security        | Sensitive customer information should be protected or anonymized.           |
| Usability       | Business users should understand the dashboard without technical knowledge. |
| Availability    | Reports should be available whenever management needs them.                 |
