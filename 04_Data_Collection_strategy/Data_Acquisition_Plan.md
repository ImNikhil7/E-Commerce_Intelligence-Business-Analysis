# Data Acquisition Plan

## Primary Source

Olist Brazilian E-Commerce Public Dataset

## Acquisition Method

Download the original relational datasets from the official
Olist Kaggle dataset.

## Raw Data Policy

Original downloaded files will be preserved without modification.

## Processing

Raw data
→ Validation
→ Cleaning
→ Transformation
→ Standardized schema
→ Database

## Additional Sources

Additional sources will only be introduced when they address
a documented data gap.

## Synthetic Data

Synthetic data will only be introduced where real data is
unavailable and the business use case remains meaningful.

All synthetic fields will be explicitly documented.
